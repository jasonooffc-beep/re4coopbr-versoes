# RE4 Co-op BR — versões

Este repositório guarda **só as versões prontas** do RE4 Co-op BR (mod co-op para Resident Evil 4 Remake).
O botão **ATUALIZAR** da aba *JOGAR JUNTO* baixa daqui.

- `atualizacao.json` — versão atual e SHA-256 de cada arquivo (o mod confere antes de instalar).
- `arquivos/` — os arquivos do mod daquela versão.
- **Releases** — o zip de cada versão para instalar à mão.

Requer o [REFramework](https://github.com/praydog/REFramework).
