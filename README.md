# RE4 Co-op BR — versões

Mod co-op para Resident Evil 4 Remake (cada um no seu PC, convite pela Steam).

## Instalar (2 downloads, links diretos)

1. **REFramework** (obrigatório): **[baixar REFramework.zip](https://github.com/praydog/REFramework-nightly/releases/latest/download/REFramework.zip)**
   Abra o zip e coloque o `dinput8.dll` na pasta do jogo (onde fica o `re4.exe`).
2. **Mod**: **[baixar RE4CoopBR.zip](https://github.com/jasonooffc-beep/re4coopbr-versoes/releases/latest/download/RE4CoopBR.zip)**
   Feche o jogo e extraia o zip **dentro da pasta do jogo**, substituindo tudo.

⚠️ Não use o botão verde "Code > Download ZIP" nem "Source code (zip)": eles **não** são o mod.

Depois de instalado, as versões novas chegam pelo botão **ATUALIZAR** da aba *JOGAR JUNTO*.

---
Para o atualizador: `atualizacao.json` (versão e SHA-256 de cada arquivo) e `arquivos/` (os arquivos da versão).
